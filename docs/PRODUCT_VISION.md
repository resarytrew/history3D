# Видение продукта

HISTORIA 3D — музей, в котором историю изучают через 3D. Пользователь сначала видит объект, затем замечает деталь, формулирует вопрос, исследует и лишь после этого читает объяснение и проверяет источники.

Первый зал «Древняя Русь» охватывает IX–XIII века. Связанные скандинавские и варяжские материалы допустимы только там, где они объясняют происхождение Руси, торговые пути, военное дело и культурные контакты.

Проект не является LMS: нет оценок, XP, регистрации, рейтингов или чата. Успех UX измеряется тем, помогает ли элемент внимательнее исследовать исторический объект.
