# Авторинг по изображениям

[← Документация](README.md)

Этот документ описывает методику работы с изображениями, вдохновлённую ранним анализом img2threejs. **Автоматическая интеграция внешнего img2threejs-сервиса или пакета не подключена к runtime HISTORIA 3D.**

## Последовательность

```text
Виды предмета + доступные измерения + provenance
→ наблюдаемые и предполагаемые свойства
→ спецификация реконструкции
→ editable procedural factory или GLB
→ фиксированные ракурсы и сравнение с references
→ проверка формы, сопряжений, материалов и ресурсов
→ версия content package
```

Одна фотография не подтверждает скрытую сторону, толщину, материал или масштаб. Неподтверждённые решения отмечаются как inference/reconstruction; числовой размер требует отдельного основания.

## Практика в репозитории

Рабочие примеры — процедурные исходники пакетов, скрипты рендера и экспорт пистолета. Геометрия должна сохранять именование для semantic bindings; модель и её историческое описание проверяются независимо.

В runtime передаются обычная factory или GLB и связанные данные. Референсы, результаты экспериментов и инструменты авторинга не превращаются автоматически в зависимости посетительского приложения.

При добавлении внешнего инструмента отдельно зафиксируйте его версию, формат входа/выхода, условия использования и воспроизводимость. Предыдущий анализ внешних проектов хранится в [архиве референсов](REFERENCE_ANALYSIS.md).
