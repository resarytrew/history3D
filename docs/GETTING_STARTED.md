# Запуск и окружение

[← Документация](README.md)

## Требования

- Node.js 20.19+ в ветке 20 либо 22.12+ — диапазон установленного Vite.
- npm и зависимости из `package-lock.json`.
- WebGL2 в браузере для интерактивной модели.
- Chromium для браузерных тестов Playwright.

Текущий runtime — статическое приложение. Для локального запуска не нужны backend, база данных, API-ключи или учётные записи сторонних сервисов.

## Установка

```bash
git clone https://github.com/resarytrew/history3D.git
cd history3D
npm ci
npm run dev
```

Используйте адрес из вывода Vite. Порт может измениться, если стандартный занят.

| Экспонат | Параметр URL |
| --- | --- |
| Кивер — стартовый | `?exhibit=russian-shako-1808` |
| Ружьё | `?exhibit=russian-musket-1808` |
| Пистолет | `?exhibit=russian-pistol-1798-1804` |

Параметр `exhibit` участвует в истории браузера. Неизвестный ID заменяется активным экспонатом по умолчанию. Сохранённый, но отключённый пакет не становится доступным через прямую ссылку.

## Сборка

```bash
npm run build
npm run preview
```

`build` выполняет content validation, TypeScript и Vite в режиме review. Результат — `dist/`; Vite также создаёт manifest. Адрес preview выводится в терминал.

`npm run build:production` сначала проверяет условия публикации. Текущие исследовательские статусы и DEV_ONLY-модели не проходят этот этап. Изменять их ради успешной сборки нельзя. Это отдельная граница от доступности экспоната в review-каталоге.

## Команды проекта

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Dev-сервер с обновлением модулей |
| `npm run lint` | ESLint, предупреждения считаются ошибками |
| `npm run typecheck` | Проверка TypeScript |
| `npm test` / `npm run test:watch` | Полный Vitest / режим наблюдения |
| `npm run validate:content` | Данные и файлы всех пяти пакетов, включая отключённые |
| `npm run test:e2e` | Все сценарии Playwright; часть старых ожидает скрытую коллекцию |
| `npm run build:pistol` | Экспорт пистолета и контрольные материалы |
| `npm run verify:pistol` | Экспорт и дополнительные проверки/галерея пистолета |
| `npm run verify:shako` / `verify:musket` | Рендеры и метрики соответствующей модели |
| `npm run verify:3d` | Исторически названная команда проверки Покрова, а не всех моделей |

Команды экспорта и рендера записывают файлы. Перед запуском проверьте рабочее дерево; после — просмотрите diff, чтобы не включить посторонние изменения assets. [Сценарии проверки →](TESTING.md)

## Если модель не загрузилась

Дождитесь окончания индикатора. Область модели не подменяется постером: ошибка отображается текстом. Проверьте консоль браузера и диагностические атрибуты canvas: `data-renderer`, `data-renderer-error`, состояние `.viewer-stage`.

Для WebGL2 проверьте доступность аппаратного ускорения. Для GLB — URL, ответ загрузки и корректность файла. При ошибке dynamic import после смены экспоната проверьте dev-сервер: валидатор содержимого должен использовать собственный кэш `node_modules/.vite-content-validation`, не кэш открытого viewer.

Для тяжёлого генератора пистолета используйте параметры Vitest из [руководства по тестированию](TESTING.md). Увеличенное время подготовки не означает разрешения ослабить проверки геометрии.
