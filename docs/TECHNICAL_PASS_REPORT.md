## Архитектура

`src/three/ViewerController.ts`: **375 → 123 строки** (включая пустые). Из него вынесены реализация камеры/OrbitControls, переходы, создание света и окружения, контактная тень, масштабная фигура, управление моделями и проекция точек. Остались создание renderer/scene, связка подсистем, ResizeObserver, события canvas и внешний API viewer.

| Файл в `src/three/` | Ответственность |
| --- | --- |
| `CameraRig.ts` | OrbitControls, настройка экспоната/аспекта, focus/reset/compare, переход 720 мс, reduced motion, остановка перехода при ручном вращении |
| `LightingRig.ts` | Прежние default/artifact-studio lights и environment, тени, человек для сравнения масштаба; владение и освобождение ресурсов |
| `ModelHost.ts` | Активная модель, загрузка последнего запроса, добавление в сцену, удаление/освобождение; корректная очистка при ошибке commit |
| `HotspotSystem.ts` | Привязка к именованным поверхностям, проекция и occlusion через существующий `hotspotProjection`, очистка и скрытие при сравнении |
| `RenderScheduler.ts` | Один RAF на несколько invalidate; продолжение только во время движения/затухания; отсутствие RAF в покое; pause/dispose |

`model-runtime.ts` загружает GLB через отменяемый fetch и GLTFLoader.parseAsync. Запоздавший результат парсинга освобождается. В `state/latest-request.ts` запоздавшая ошибка старой загрузки не подменяет результат новой. GLB и lazy procedural factories сохраняют прежний контракт `LoadedExhibitModel`.

Параметры runtime-освещения, FOV, contact shadow и масштаба существующих экспонатов сохранены. Контекст WebGL при потере показывает прежнее сообщение об ошибке, планировщик приостанавливается. Dispose снимает слушатели и ResizeObserver, отменяет кадр и освобождает controls, модель, тени, environment, render lists и renderer.

`src/app/MuseumApp.tsx`: **191 → 180 строк**. Минимальная разница числа строк связана с сохранением JSX-композиции; все шесть состояний выбора/панелей/сравнения/объявления и их сбросы вынесены в `src/state/useMuseumController.ts` и `museum-state.ts`. Reducer атомарно сбрасывает зависимое состояние при смене экспоната. Будущие действия можно добавить в reducer; фиктивных Assembly-полей сейчас нет.

`src/state/exhibit-url.ts` работает через URL API: прямой id задаёт начальное состояние, выбор пишет pushState, Back/Forward обрабатываются через popstate. Некорректный id заменяется default первого каталога через replaceState. Смена коллекции проходит через тот же выбор экспоната. Path/hash и посторонние параметры сохраняются, повторный выбор не создаёт дубликат history, документ не перезагружается.

## Runtime validation

Новые `src/content/schema.ts` и `validation.ts`, переписанный `scripts/validate-content.ts`, зависимость Zod в `package.json`/lockfile. TypeScript-файлы больше не проверяются поиском строк. Vite SSR загружает реальные значения пакетов и каталога вместе с импортами ресурсов.

Схемы покрывают Exhibit, HistoricalSource, EvidenceItem, ReconstructionVersion, Hotspot, ExhibitModel, presentation, credits, assets, visitor content и collections. Отдельный graph-проход проверяет sourceIds/sourceRefs, evidenceIds, все локальные id и slug, номера точек, default/entries коллекций и принадлежность экспонатов. Ошибки формы, ссылок и файлов собираются вместе; ошибка одного поля не выключает последующие проверки. Проверяются существование/ненулевой размер локальных ресурсов, граница репозитория и registry factoryId. Внешние HTTPS URL проверяются синтаксически, без непредсказуемого сетевого build gate.

Production по-прежнему требует published, запрещает developmentOnly, требует полноценные источники и RU/EN content. Формат ошибки содержит экспонат, точный путь поля и объяснение. Непрошедший публикационный статус не повышается ради сборки.

## Источники и остающаяся неопределённость

1. [Музейная карточка конкретного тульского экземпляра 1803 года](https://www.kskdivniy.ru/museum/eksponaty/pistolet-kirasirskiy-i-dragunskiy-ukorochennyy-1798-1804-gg/) и [музейная историческая справка](https://www.kskdivniy.ru/museum/news/novinki/): атрибуция, 17 мм, укорочение 370 → около 269 мм, галерея l_1–l_5.

3. [Л. К. Маковская](https://militera.org/books/pdf/tw/makovskaya_lk01.pdf), PDF с. 75–76 и с. 183, рис. 128: описание деревянного шомпола с латунной головкой и виды образца 1798. Изображения просмотрены; это типологическая опора, не обмер сокращённого экземпляра.

Статус остаётся `reconstruction`. Требуют натурного обмера или независимой исторической проверки: наружный диаметр 24 мм, общая длина, поперечные сечения, точные глубины/посадка замка, полки и казённого плеча, положения невидимых креплений и второй трубки после укорочения, форма нижнего возврата набалдашника, покрытие/сплавы. Видимый дульный канал моделируется как замкнутое визуальное углубление; рабочие внутренности, камера и резьбы отсутствуют. Кремень — явное поясняющее добавление к музейным пустым губкам. Вензель, клейма, история ремонтов, инвентарный номер и участие именно этого предмета в войне 1812 года не установлены. Техническая проверка не заменяет историческую экспертизу.
