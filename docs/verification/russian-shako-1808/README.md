# Кивер образца 1808 года — визуальная и инженерная проверка

Версия 0.2.0. Исторический статус: **PENDING HUMAN REVIEW**. Это реконструкция по заданию и визуальным источникам, а не музейный скан. Визуальная доработка сохраняет зафиксированные размеры, конструкцию, бело-зелёный репеёк и состав этишкета: три кисти справа от носителя (−X), одна слева (+X).

## Источники и границы реконструкции

Применён предоставленный [generic-extract-skill.md](https://github.com/img2threejs/img2threejs/blob/main/skills/generic-extract-skill.md). Разбор macro / components / materials / topology и дополнение находятся в `intake.json`. Навык описывает метод извлечения формы; историческим источником он не является.

Изначально были предоставлены шесть изображений. Изображения 4 и 6 дублируются; орёл, султан и цветные кисти на отдельных фотографиях не относятся к выбранной конфигурации. В версии 0.2.0 использована дополнительно предоставленная [фотография накладки «Гренада об одном огне»](https://archaeolog.ru/media/smolensk/Бляха-накладка%20Гренада%20об%20одном%20огне.jpg): широкое пламя с продольными рёбрами, два поперечных пояска и округлая выпуклая бомба. Контур и рельеф восстановлены по этим признакам. Археологическая коррозия не перенесена на исправный предмет обмундирования.

Предоставленный [PDF Алехина и Ульянова](https://www.reenactor.ru/ARH/PDF/Alexin-Ylianov.pdf) открыт для сверки описания конструкции. Размеры сохранены по зафиксированной спецификации. Изображение с museumgagarin.ru не удалось открыть из-за тайм-аута; оно не использовано как проверенное свидетельство. Поиск дополнительных исторических источников не проводился.

Гренада около 73 × 29 мм, лист 0,6 мм и рельеф около 1,4 мм — **RECONSTRUCTION**. Фотография помогает восстановить пропорции и устройство рельефа, но не устанавливает абсолютные размеры, профиль штамповки и принадлежность конкретной накладки выбранному варианту формы. Эти вопросы остаются для историка.

## Что изменено

- Гренада: тонкая объёмная накладка, асимметричный контур одного пламени, семь сходящихся рёбер, два поперечных пояска и неглубокая выпуклая бомба. Декоративного кольца вокруг бомбы нет. Используется геометрия, не плоская фотография.
- Кожа: пространственная микрофактура в метрах и слабая неоднородность шероховатости. Чёрный козырёк имеет более выраженный блеск, отдельные ранты и контрастные отражения. Войлок сохраняет матовую волокнистую поверхность и отличается от кожаных полос.
- Швы: матовая вощёная нить, небольшая нерегулярность стежков, швы вдоль кромок V-полос и горизонтальных поясов. Основная геометрия не деформирована.
- Этишкет: молочно-кремовый хлопок, перекрёстное плетение трёх прядей, микрорельеф кручёных волокон, мягкое отклонение подвесов, объёмная обмотка головок кистей и неодинаковые нити бахромы. Схема плетения остаётся реконструкционным приближением.
- Свет: общий для контрольного рендера и экспоната набор световых панелей, тёмные промежутки между отражениями, заполняющий и контровой источники. Пресет включается только у кивера; при смене экспоната восстанавливается прежнее освещение. Ресурсы окружения освобождаются при уничтожении просмотрщика.

Материалы процедурные. Микрофактура изменяет нормали и шероховатость, не размеры и силуэт. Искусственные царапины, зелёная патина, трещины и археологические повреждения не добавлялись.

## Воспроизведение и изображения

```sh

# /?exhibit=russian-shako-1808
npm run verify:shako -- --pass=1
npm run verify:shako -- --pass=2
npm run verify:shako -- --pass=3
npm run verify:shako -- --pass=4
npm run verify:shako
npx vitest run tests/shako-procedural.test.ts tests/procedural-registry.test.ts
npx playwright test e2e/shako.spec.ts
```

Рендеры создаёт настоящий Three.js WebGLRenderer в Chromium/SwiftShader. На каждом проходе сохраняются front / front-right / right / rear-right / rear / left / top и метрики. Азимут отсчитывается от +Z к +X; `left` показывает правую сторону носителя и три кисти.

Камера: FOV 34°, 800 × 900, цель (0, 0.16, 0), горизонтальный радиус 0.91 м, высота над целью 0.12 м. Верхний ракурс использует то же расстояние до цели. Все ракурсы используют фиксированный свет; окружение и экспозиция совпадают с runtime. Runtime дополнительно рисует тень на подложке.

`fidelity-before/` содержит предыдущие семь финальных ракурсов, метрики и описание версии 0.1.0. Они позволяют сравнить сохранённую форму до и после доработки; освещение намеренно изменено. `fidelity-badge.png`, `fidelity-leather.png`, `fidelity-textile.png` — отдельные крупные планы, а не увеличенные фрагменты маленького изображения. `integration-chromium.png` и `integration-mobile.png` показывают интерфейс. Poster обновлён из финальной геометрии; thumbnail отрендерен отдельно в 320 × 240.

## Технический результат

**145 892 треугольника, 54 mesh**, включая Interior; **143 668 видимых треугольников, 51 draw call** в студии без теневого прохода. Границы внешней сборки: **292.100 × 302.000 × 307.862 мм**. Высота всей сборки включает репеёк и ремень, поэтому отличается от высоты тульи.

Задание разрешает увеличение целевых 100 тысяч до 150 тысяч треугольников для детализации этишкета и знака. Этот резерв использован на изгибы плетения, кручёные подвесы, обмотку головок кистей и штампованный рельеф. Число mesh и draw calls не выросло: мелкие детали объединены. Тест ограничивает бюджет 150 тысячами.

Пройдены lint, typecheck, review build и 29 unit-тестов. Два E2E-сценария проверяют desktop/mobile: шесть точек исследования, объяснения, вращение, сброс, масштаб, переключение коллекций без замены canvas, восстановление светового пресета и отсутствие ошибок шейдеров. Контрольный renderer также завершает проверку ошибкой при сбое WebGL или JavaScript.

Пакет остаётся `historical-review` / `developmentOnly: true`. Ограничение публикации не изменено. Визуальная проверка не заменяет историческую экспертизу и не превращает размеры непроверенных деталей в FACT.
