# Кивер образца 1808 года — инженерная проверка

Исторический статус: **PENDING HUMAN REVIEW**. Это source-based reconstruction по фиксированному заданию пользователя, а не скан или копия конкретного сохранившегося предмета. Исторический поиск в интернете не проводился.

## Входные данные и img2threejs

Применён [generic-extract-skill.md](https://github.com/img2threejs/img2threejs/blob/main/skills/generic-extract-skill.md): M.C.M.T-анализ сохранён в `intake.json`. Этот короткий навык требует JSON-разбора макроформы, компонентов, материалов и топологии. Расширенные поэтапные gates взяты из задания пользователя. Навык не является историческим источником.

Предоставленные изображения показывают несколько конфигураций. Чертёж с другими размерами, орёл, высокий султан и цветные кисти не переносятся в выбранную модель. Изображения 4 и 6 дублируются. Отдельного читаемого фронтального референса однопламенной гренады среди вложений нет: её точный контур нельзя считать скопированным из статьи.

## Воспроизведение

```sh
npm run dev
# /?exhibit=russian-shako-1808
npm run verify:shako -- --pass=1
npm run verify:shako -- --pass=2
npm run verify:shako -- --pass=3
npm run verify:shako -- --pass=4
npm run verify:shako
npx vitest run tests/shako-procedural.test.ts tests/procedural-registry.test.ts
npx playwright test e2e/shako.spec.ts
```

Рендеры получены настоящим Three.js WebGLRenderer в Chromium/SwiftShader. Фабрика, материалы и топология совпадают с runtime. Это не CPU-проекция треугольников. На каждом проходе сохраняются front / front-right / right / rear-right / rear / left / top и метрики. Азимуты отсчитываются от +Z к +X; исторические «справа/слева» относятся к носителю: его правая сторона — −X. Поэтому файл `left` показывает три правые кисти.

Камера: PerspectiveCamera, FOV 34°, 800 × 900, целевая точка (0, 0.16, 0), горизонтальный радиус 0.91 м, высота над целью 0.12 м. Верхний ракурс использует то же расстояние до цели. Освещение фиксировано во всех ракурсах; production viewer имеет своё штатное освещение. Draw calls в JSON относятся к объекту в студии без теневого прохода; полная сцена приложения добавляет тени и другие объекты.

## Инженерные изменения по результатам осмотра

1. Blockout: умеренное расширение, отсутствие вогнутых стенок и вынос козырька читаются без украшений. Сверху первоначально исчезал центр дна: причина — направление нормалей lathe-поверхности. Порядок профиля исправлен; тест проверяет попадание луча сверху и глубину 25 мм.
2. Construction: отдельные V-полосы, карман с верхним отверстием, задняя кожаная накладка и пряжка. Регулировочный разрез прорезан в самой нижней геометрии войлока. Он прикрыт кожей; задняя сторона не копирует переднюю.
3. Identity: гренада имеет одну вертикальную огненную композицию над округлой бомбой. Репеёк сплюснут в глубину. Косицы и подвесы объёмные, кисти расположены асимметрично. Траектория плетения остаётся реконструкционным приближением.
4. Materials: первоначальная верхняя обшивка пересекалась с войлоком и давала мерцающие полосы. Скрытый войлок убран внутрь оболочки. В студии уменьшена экспозиция для сохранения читаемости белого плетения. Кожа даёт гладкие блики, войлок — рассеянную матовую поверхность. Микрофактура процедурная, без изображений и искусственных повреждений.
5. Microdetails: швы объединены в один mesh. Размерный тест выявил погрешность ширины диагонального ремня при плоском расчёте. Расчёт переведён в ортонормальный базис поверхности конуса; ширина проверяется по вершинам сгенерированной геометрии.

Все длины находятся в `shako1808Dimensions.ts`, в метрах. Высота всей внешней сборки включает репеёк, подбородочный ремень и толщину козырька и не равна высоте тульи. Скрытый `Interior` содержит готовые LeatherSweatBand, LinenLiner и NeckFlap; он учитывается в общем triangle budget, но исключён из внешнего bounding box и draw calls.

Остаются для историка: точный силуэт и рельеф конкретного знака, подробная схема плетения, размеры репейка, толщины и производственные варианты. Форма кистей, расположение свободного ремня, карманный зазор, микрокривизна и скрытые складки — инженерные допущения. Технические проверки не превращают их в FACT.

Пакет имеет `historical-review` и `developmentOnly: true`: доступен в review-сборке, существующий publication gate не обойдён. Фон — однотонная студийная заглушка; историческую среду подготовят кадеты.

## Результат технической проверки

Полная геометрия: **74 144 треугольника, 54 mesh**, включая скрытый Interior. Внешний вид: **71 920 треугольников, 51 draw call** в фиксированной студии. Внешний bounding box: **292.043 × 302.000 × 307.740 мм** (X × Y × Z). Нижняя граница Y = 22 мм, верхняя = 324 мм; координата нижнего края тульи — 80 мм. Числа получены из геометрии, подробности в `pass-5-metrics.json`.

Измеренные контрольные длины: 175.000 / 255.000 / 210.000 / 75.000 / 17.985 / 20.000 мм. Геометрические gates пройдены с указанными в тестах допусками. Сохранены 35 фиксированных изображений пяти проходов и desktop/mobile screenshots. Визуальных пересечений, мерцания верхней обшивки или отсутствующих сторон после исправлений не выявлено. Точное соответствие отсутствующему референсу знака и плетения не заявляется.

Интеграция использует один экземпляр WebGL renderer при смене коллекций; lazy registry поддерживает старую procedural factory и GLB loader. Метровый масштаб учтён в отсечении камеры, допуске перекрытия hotspots, тени и сравнении с ростовой фигурой. Вопросы доступны до раскрытия объяснений. Мобильный carousel с одним экспонатом не перекрывает точку козырька.
