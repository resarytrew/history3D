## Проверка маркеров

Новый модуль `src/three/hotspotProjection.ts` привязывает точку к указанному semantic mesh лучом вдоль заданной внешней нормали. При движении камеры координаты проецируются после рендера в том же animation frame. React отвечает за создание кнопок, но не задерживает их координаты через обновление state.

Маркеры скрываются, если нормаль обращена от камеры, точка вышла за объём видимости или луч перекрыт видимым mesh. Скрытая группа Interior исключена из пересечений. Точки не прижимаются к экранным границам и не получают произвольных экранных смещений. При статичной камере лишние пересчёты не выполняются.

Тесты проверяют исходный ракурс, 48 углов полного оборота, точное совпадение с проекцией связанной поверхностной точки, скрытие передних знаков сзади, исключение скрытых мешей и перекрытие видимым объектом. E2E вращает реальную сцену мышью, проверяет исчезновение передних цифр сзади и возврат в исходные координаты после сброса. `markers-rear-chromium.png` и `markers-rear-mobile.png` показывают результат.
