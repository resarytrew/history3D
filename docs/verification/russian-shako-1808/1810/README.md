# Проверка версии 0.4.0

Дата: 06.09.2026. Историческая цель: рядовой мушкетер 1-го батальона, 1810 год.
Основания, трактовки размеров и ограничения: [таблица доказательств](../evidence-1810.md).

## Результат

- 227284 треугольника, все доступны для осмотра; 54 mesh и 54 draw calls в контрольной сцене без теневого прохода. Исходно 169076 треугольников. Новая геометрия относится к подкладке, назатыльнику, основе репейка и креплениям.
- Вычисленные габариты тульи: высота 172.244 мм, наружный верх 264.587 мм, наружный низ войлока 215.138 мм. Полная сборка примерно 290.446 × 294.518 × 316.062 мм. Дополнительные знаки после запятой в JSON отражают вычисление, не историческую точность.
- Внутренность видна при вращении снизу. Верх имеет обратную поверхность, через шапочку не просвечивает фон. Назатыльник убран внутрь.
- Подбородочная пряжка и гренадерский карман исключены. Ремень не пересекает козырёк; его провисание остаётся реконструкционным.
- Отрисовка неподвижной сцены и повторное вычисление её теней остановлены. Полигональная сетка и качество материалов при этом сохранены. Тень технической подставки скрывается при осмотре снизу.

## Проверки

| Команда / проверка | Итог |
|---|---|
| `npm run build` | Успех; проверка контента, TypeScript и review-сборка. Два ожидаемых предупреждения о developmentOnly |
| `npm run typecheck` | Успех |
| `npm run lint` | Успех |
| `npm test` | 36 тестов, 7 файлов, все прошли |
| `npx playwright test --reporter=list` | 19 прошли, 1 штатно пропущен: мобильная компоновка в desktop-проекте |
| `npx playwright test e2e/shako.spec.ts --reporter=list` после последних правок ремня и вида снизу | Все 6 сценариев desktop/mobile прошли |
| `npm run verify:shako -- --1810 --hero` | Успех; финальные метрики, изображения, постер и миниатюра; ошибок WebGL/шейдеров не зарегистрировано |
| `git diff --check` | Без ошибок пробелов |

Первый полный браузерный прогон выявил тайм-ауты снимков/взаимодействия и сравнение строк координат после сброса. После прекращения лишней отрисовки и проверки возвращения маркеров в пределах 0.25 пикселя полный прогон прошёл. На промежуточном параллельном запуске два модульных теста превысили 5 секунд; последовательный финальный запуск всех 36 прошёл. Проверки не ослаблялись скрытием ошибок WebGL, удалением геометрии или пропуском сценариев кивера.

## Изображения

- `pass-5-*`: общие виды, включая верх, низ и технический разрез. Разрез использует плоскость отсечения, без дорисованной поверхности среза.
- `01-*`…`08-*`, `badge-*`, `repyok-*`, `fidelity-*`: материалы, швы, знаки, косицы и кисти.
- `integration-*`, `markers-rear-*`, `underside-*`, `scale-comparison.png`: реальное приложение на desktop/mobile.
- `pass-5-metrics.json`: размеры, геометрия и показатели каждого ракурса.

Независимая историческая экспертиза ожидается. Обмеры гренады и репейка, состав сплава, точное крепление и складки не объявлены установленными фактами. Пакет сохраняет historical-review и developmentOnly.
