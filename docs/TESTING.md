# Проверки и приёмка

[← Документация](README.md)

Разделяйте проверку кода, проверку исторических данных и оценку качества реконструкции. Успешный build подтверждает техническую сборку, но не историческую достоверность.

## Быстрые проверки

```bash
npm run lint
npm run typecheck
npm run validate:content
npm run build
```

Content validation охватывает все пять пакетов, включая два отключённых. Предупреждения DEV_ONLY допустимы в review и блокируются production-проверкой.

## Unit и integration

```bash
npm test -- --maxWorkers=2 --hookTimeout=120000
```

Ограничение workers полезно на машине, где одновременно работают генераторы и браузер. Увеличенный hook timeout позволяет закончить тяжёлую подготовку пистолета. Assertions остаются прежними.

Профильный набор семантического взаимодействия:

```bash
npm test -- tests/assembly-v2.test.ts tests/semantic-controls.test.tsx tests/semantic-scene.test.ts tests/semantic-presentation.test.ts tests/camera-rig.test.ts
```

На срезе от 10 сентября 2026 этот набор содержит 25 успешных тестов. Полный набор: 93 теста, 84 pass / 9 fail. Это результаты датированного запуска, а не гарантия для будущего checkout.

## Известные падения

| Область | Причина на проверенном срезе |
| --- | --- |
| catalog — 2 теста | Ожидают отключённые Покров и шлем |
| exhibit-url — 2 теста | Ожидают маршрутизацию к отключённым экспонатам |
| MuseumApp — 4 теста | Ожидают скрытую коллекцию, её материалы или элементы карусели |
| pistol — 1 тест | Лимит 150000 треугольников при фактических 249480 |

Не возвращайте коллекцию и не меняйте лимит только ради зелёного набора. Исправление этих несоответствий оформляется отдельным изменением.

Сохранение количества «9» недостаточно: сравниваются suite, test name и причина, а неполные suites и новые пропуски считаются проблемой.

```bash
npm test -- --maxWorkers=2 --hookTimeout=120000 --reporter=json --outputFile=artifacts/assembly-v2-results.json
node node_modules/tsx/dist/cli.mjs scripts/compare-test-baseline.ts artifacts/assembly-v2-baseline-complete.json artifacts/assembly-v2-results.json
```

Первая команда имеет ненулевой exit code при известных падениях. Команда сравнения должна завершиться с 0. Исчезновение старого падения также требует объяснения и явного обновления baseline.

## Браузер

Установите браузер после установки зависимостей:

```bash
npx playwright install chromium
```

Проверенный набор для текущего семантического интерфейса:

```bash
npm run test:e2e -- e2e/assembly.spec.ts e2e/pistol.spec.ts e2e/content-validation.spec.ts e2e/viewer-lifecycle.spec.ts
```

Playwright запускает Vite на `127.0.0.1:4173` или использует уже работающий сервер. Проекты — desktop Chromium и мобильная эмуляция Chromium; мобильная эмуляция не является тестированием Safari на физическом iPhone.

На срезе от 10 сентября эти четыре файла дали 10/10. Общий `npm run test:e2e` включает также старые сценарии Покрова/шлема, ожидающие отключённую коллекцию; результат 10/10 не относится ко всему E2E-набору.

Для воспроизводимости не запускайте несколько независимых Playwright-команд против одного автоматически управляемого сервера одновременно: завершение первой может остановить сервер второй.

## Что проверять вручную

- Реальный WebGL2, вращение, масштаб, reset и смену предмета.
- Для пистолета — direct click, пустое нажатие, hover и отсутствие выбора после drag/pinch/cancel.
- Синхронность дерева, карточки и 3D; отсутствие виртуальных групп в part-of.
- Overview и оба drill-down на ширинах 320, 390, 768, 1280 CSS px; расположение панелей.
- Возврат reference view, отсутствие пересечений в конечной опорной позе, сохранение вида при ошибке solver.
- Клавиатуру, RU/EN и reduced-motion; procedural и настоящий GLB.
- Источники, оговорки, адресатов аннотаций и точность anchors.

Гарантия зазора не распространяется на свободно повёрнутую или промежуточную позу. Автоматические скриншоты дополняйте осмотром на устройстве с аппаратным ускорением.
