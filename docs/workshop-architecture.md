# Цифровая мастерская историка

Будущий `/workshop` — отдельное authoring-приложение поверх тех же schemas, но не часть музейного runtime. Оно ведёт пакет через object, sources, evidence, spec, build, historical review, technical review и publication. Первая версия может быть CLI + файловые шаблоны; backend нужен только при появлении совместной работы и прав доступа.
