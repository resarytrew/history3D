# Workflow реконструкции

[← Документация](README.md)

```text
Предмет и вопрос → источники → evidence → спецификация
→ модель → контрольные виды → историческая и техническая проверка
→ версия пакета → решение о публикации
```

## 1. Предмет и основания

Определите прототип, период, состояние сохранности и границы работы. Выпишите размеры, признаки и противоречия источников. Отдельно обозначьте свойства, которые невозможно восстановить по имеющимся данным.

Результат этапа — проверяемая исследовательская запись, а не набор картинок без происхождения.

## 2. Спецификация

Опишите масштаб и координаты, части и их отношения, допустимые допущения и критерии приёмки. Семантическая структура фиксирует предмет. Учебные layouts планируются отдельно.

Если задача ограничена наружной геометрией, не добавляйте внутренний механизм или работоспособность как подразумеваемое свойство.

## 3. Построение

Создайте procedural factory либо подготовьте GLB. Сначала проверяйте общий силуэт и пропорции, затем сопряжения, отдельные детали и поверхности. Сохраняйте стабильные geometry bindings.

Авторьте anchors в нужных semantic frames. Переносите старые материалы в annotations по их смыслу, сохраняя ID, evidence references и оговорки.

## 4. Проверка

Снимите фиксированные общие и крупные виды, сравните их с исходными свидетельствами. Измерьте геометрию и ресурсы, проверьте round trip GLB, интерфейс и поддерживаемые размеры экрана.

Исторические и технические замечания фиксируйте раздельно. Браузерный PASS не доказывает правильности атрибуции. [Команды проверки →](TESTING.md)

## 5. Поставка

Зафиксируйте версию, изменения evidence, modelHash при наличии, результаты и нерешённые вопросы. Включайте в runtime только предназначенные для него ресурсы; исходные references и эксперименты остаются в authoring-материалах.

Обновите руководство пакета, если изменился способ загрузки или исследования. Датированные отчёты сохраняйте как историю; текущий статус описывайте в актуальной документации.

Публикационный статус меняется по результатам соответствующей проверки, а не автоматически после экспорта модели.
