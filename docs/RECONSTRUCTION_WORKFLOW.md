# Workflow реконструкции

```text
OBJECT → SOURCES → EVIDENCE → RECONSTRUCTION SPEC
→ 3D BUILD → MULTI-ANGLE REVIEW → HISTORICAL REVIEW
→ TECHNICAL REVIEW → PUBLICATION
```

Исходники, промежуточные mesh/texture experiments и review renders не являются runtime assets. Одобрение охватывает конкретный hash, версию модели, источники, модификации, license и ограничения. Новое свидетельство создаёт новую reconstruction version вместо тихой перезаписи прошлого результата.
